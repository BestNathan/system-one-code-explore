# Nession WebSocket Range-Only System One Runtime v0 — 2026-09-23\n\n## Question\n\nCan Phase 2 be reduced to a content-agnostic runtime loop where the harness only manages files, line ranges, coverage, raw observations, and action execution, while System One makes every semantic exploration decision?\n\nThe v0 loop is:\n\n~~~text\nState\n  -> generate dynamic ReadRange / StopTask actions\n  -> System One independently scores actions\n  -> execute every read above the parallel threshold\n     or execute top-1 read when none exceed the threshold\n  -> if StopTask is both above threshold and globally best, stop\n  -> raw observations enter State\n  -> generate the next action space\n  -> repeat\n~~~\n\nThe harness performs no AST, LSP, symbol, import, keyword, semantic-chunk, or source-content analysis.\n\n## Action space\n\nThe only effects are:\n\n~~~text\nReadRange(path, start_line, end_line)\nStopTask\n~~~\n\nReadRange carries a navigation label for the model:\n\n~~~text\nseed_head\nseed_middle\nseed_tail\nexpand_before\nexpand_after\njump\n~~~\n\nThe labels do not change the effect. Unread files expose head/middle/tail probes. Previously read files expose before/after around the most recent read plus midpoint probes into up to two largest unread gaps. This uses coverage geometry only.\n\n## Selection policy\n\nWith parallel threshold 0.65:\n\n~~~text\nif StopTask >= 0.65 and StopTask >= best ReadRange:\n    stop\n\nelse if any ReadRange >= 0.65:\n    execute all ReadRange actions >= 0.65\n\nelse:\n    execute the single highest-scoring ReadRange\n~~~\n\nTherefore a low-confidence frontier never causes harness-driven termination.\n\n## RuntimeState versus DecisionView\n\nEarly attempts failed with TypeSafe `max_tokens_exceeded`. Transport-batching questions alone did not solve it because the durable RuntimeState can grow beyond the model context.\n\nv0 now preserves every observation in RuntimeState while projecting a deterministic, content-agnostic DecisionView:\n\n- coverage metadata for every file;\n- the most recent complete raw observations that fit a 48,000-character budget;\n- explicit visible/omitted observation counts.\n\nNo text is summarized or semantically filtered.
